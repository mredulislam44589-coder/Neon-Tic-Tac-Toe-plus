# Neon-Tic-Tac-Toe-plus
Neon TicTacToe is a high-energy arcade twist on the classic strategy game! Featuring stunning cyberpunk neon graphics, real-time online rooms, smart AI opponents, custom nicknames, and an exciting coin betting system (+15 for wins, -15 for losses). Play solo, pass-and-play locally, or host live multiplayer matches anywhere!
